# dermodyai-nou-demo

Demo project for a proposal assistant and a business-development research agent.

## Structure

- `/proposal-agent` — proposal drafting assistant
- `/bd-research-agent` — SAM.gov and USASpending research, 1–5 scoring, and BD briefs
- `/shared` — shared utilities (empty)

The BD research demo is documented in [bd-research-agent/DEMO.md](bd-research-agent/DEMO.md). It ships with a fictional contractor profile. Do not point a prospect demo at an archived client profile.
